# SifarMenu

A dark-themed restaurant website concept featuring an Italian-inspired menu.

## Features

- Home, About, Menu, and Contact sections
- Menu items grouped into pasta, pizza, and desserts
- Client-side menu category filters

## Run locally

Open `index.html` in a web browser. No build step or dependencies are required.
